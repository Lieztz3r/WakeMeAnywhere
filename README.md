# Wake Me Anywhere

**Install the latest version:** [Download Wake Me Anywhere](https://github.com/Lieztz3r/WakeMeAnywhere/releases/latest)

## Recommended: one-tap installer

1. On Android, download [WakeMeAnywhere-Instalador.apk](https://github.com/Lieztz3r/WakeMeAnywhere/releases/latest/download/WakeMeAnywhere-Instalador.apk) and open it.
2. If Android asks, allow your browser and then the installer to install unknown apps.
3. Tap **Install / Update**. The installer downloads the latest official app, checks its signature and installs it. Internet access is required.

Requires Android 8.0 (Android 26) or later. You can also [download the full APK directly](https://github.com/Lieztz3r/WakeMeAnywhere/releases/latest/download/WakeMeAnywhere.apk).

**Use only APKs attached to this official repository's releases.** APKs are signed with the project key; `latest.json` includes the app version and SHA-256 used by the installer. The `.aab` format is not for direct installation.

## Privacy

Location used to trigger alarms is processed on the phone and is not sent to the developer. The map requests tiles from OpenFreeMap. Place searches and reverse-geocoding requests can send search text, approximate area or selected coordinates to Nominatim. Optional live location sharing is encrypted on the device before it is relayed through ntfy; the relay still sees connection metadata. Read the [full privacy policy](PRIVACY.md).

This repository distributes ready-to-install releases and end-user information; it does not contain the development source code.

# Wake Me Anywhere (español)

**Instala la última versión:** [Descargar Wake Me Anywhere](https://github.com/Lieztz3r/WakeMeAnywhere/releases/latest)

## Recomendado: instalador automático

1. En tu teléfono Android, descarga [WakeMeAnywhere-Instalador.apk](https://github.com/Lieztz3r/WakeMeAnywhere/releases/latest/download/WakeMeAnywhere-Instalador.apk) y ábrelo.
2. Si Android lo solicita, permite instalar aplicaciones desde el navegador y luego desde el instalador.
3. Pulsa **Instalar / actualizar**. El instalador descarga la aplicación oficial más reciente, verifica su firma y la instala. Necesitas conexión a Internet.

Requiere Android 8.0 (Android 26) o posterior. También puedes [descargar el APK completo directamente](https://github.com/Lieztz3r/WakeMeAnywhere/releases/latest/download/WakeMeAnywhere.apk).

**Usa únicamente APK adjuntos a las publicaciones oficiales de este repositorio.** Los APK se firman con la clave del proyecto; `latest.json` contiene la versión y el SHA-256 que comprueba el instalador. El archivo `.aab` no se puede instalar directamente.

## Privacidad

La ubicación que activa alarmas se procesa en el teléfono y no se envía al desarrollador. El mapa solicita teselas a OpenFreeMap. Las búsquedas de lugares y la resolución del nombre de un punto pueden enviar texto de búsqueda, una zona aproximada o coordenadas seleccionadas a Nominatim. Si activas la ubicación en vivo, se cifra en el dispositivo antes de enviarse por ntfy; el relé aún ve metadatos de conexión. Consulta la [política de privacidad completa](PRIVACY.md).

Este repositorio distribuye versiones listas para instalar e información para usuarios; no contiene el código fuente de desarrollo.
