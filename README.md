# Wake Me Anywhere

**Install the latest version:** [Wake Me Anywhere 1.0.0](https://github.com/Lieztz3r/WakeMeAnywhere/releases/latest)

## Recommended: one-tap installer

1. On your Android phone, download [WakeMeAnywhere-Instalador.apk](https://github.com/Lieztz3r/WakeMeAnywhere/releases/latest/download/WakeMeAnywhere-Instalador.apk) and open it.
2. If Android asks, allow your browser to install unknown apps, then allow the installer as well.
3. Tap **Install / Update** in the installer. It downloads the latest official app, verifies its signature, and installs it. Internet access is required.

Requires Android 8.0 (Android 26) or later.

## Install the app directly

Alternatively, download [WakeMeAnywhere.apk](https://github.com/Lieztz3r/WakeMeAnywhere/releases/latest/download/WakeMeAnywhere.apk), open it on your phone, and follow Android's installation prompt. This installs version 1.0.0; use the small installer above to check for future releases automatically.

**Use only the APKs attached to the official release.** The `.aab` format is not for direct installation. This download repository contains the ready-to-install app and its installer, not the development source code.

# Wake Me Anywhere (español)

**Instala la última versión:** [Wake Me Anywhere 1.0.0](https://github.com/Lieztz3r/WakeMeAnywhere/releases/latest)

## Recomendado: instalador automático

1. En tu teléfono Android, descarga [WakeMeAnywhere-Instalador.apk](https://github.com/Lieztz3r/WakeMeAnywhere/releases/latest/download/WakeMeAnywhere-Instalador.apk) y ábrelo.
2. Si Android lo solicita, permite instalar aplicaciones desde el navegador y luego desde el instalador.
3. Pulsa **Instalar / actualizar**. El instalador descarga la aplicación oficial más reciente, verifica su firma y la instala. Necesitas conexión a Internet.

Requiere Android 8.0 (Android 26) o posterior.

## Instalar la aplicación directamente

También puedes descargar [WakeMeAnywhere.apk](https://github.com/Lieztz3r/WakeMeAnywhere/releases/latest/download/WakeMeAnywhere.apk), abrirlo en el teléfono y seguir las instrucciones de Android. Para buscar futuras versiones automáticamente, usa el instalador pequeño.

**Descarga únicamente los APK adjuntos a esta publicación oficial.** El archivo `.aab` no se puede instalar directamente. Este repositorio contiene la aplicación lista para instalar y su instalador; no incluye el código fuente de desarrollo.
